# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple application that calculates the interest earned or payable on a principal amount over a specified period at a fixed annual interest rate.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal Amount
- Annual Interest Rate (in percentage)
- Time Period (in years)

## Output
- Simple Interest
- Total Amount (Principal + Simple Interest)

## Technologies Used
- HTML
- CSS
- JavaScript

## Example
Principal Amount: ₹10,000  
Rate of Interest: 5% per year  
Time: 2 years  

Simple Interest = ₹1,000  
Total Amount = ₹11,000

## Conclusion
This project demonstrates the basic calculation of simple interest using a mathematical formula.
